# Экономическое воздействие COVID

Итоговое задание по дисциплине «Java для Data Science». Вариант 10.
Кирилов Андрей Сергеевич, группа ДФиАД25-1.

Консольное приложение читает учебный файл `Exposure.csv`, преобразует строки
в объекты стран и формирует отчёт. Исходный CSV взят из материалов дисциплины
и включён в проект без изменений. Он содержит исторические данные.

## Как запустить

Нужен JDK 17 или новее. В IntelliJ IDEA откройте `pom.xml` как Maven-проект,
выберите JDK и запустите класс `ru.netology.kirilov.Main`.

Для сборки из командной строки также нужен Maven. Выполните команды в папке проекта:

```text
mvn clean package
java -jar target/covid-economic-exposure.jar
```

Программа создаст `report.txt` в текущей рабочей папке. Чтобы сохранить отчёт
под другим именем или в другой папке, передайте путь единственным аргументом:

```text
java -jar target/covid-economic-exposure.jar results.txt
```

Папка для отчёта должна существовать. Если программа не найдёт CSV, обнаружит
неверный заголовок или не сможет записать отчёт, она сообщит об ошибке
и завершит работу с ненулевым кодом.

## Что входит в отчёт

- Число стран и количество записей с заполненным общим индексом.
- Максимальный и средний общий индекс экономической уязвимости.
- Группы дохода и число стран в каждой группе.
- Страна с максимальным общим индексом среди стран с низким доходом (LIC).
- Страны с индексом без учёта помощи, прямых иностранных инвестиций (ПИИ)
  и продовольственного импорта от 5 до 6 включительно; число стран LIC в этой выборке.
- Результаты создания, поиска, изменения и удаления учебной записи.

Учебная запись нужна для проверки операций CRUD. Перед расчётом показателей
программа удаляет её, поэтому она не влияет на статистику. Если несколько стран
в группе имеют одинаковый максимальный индекс, программа возвращает первую
из них по порядку в CSV.

## Данные и пропуски

В CSV 22 колонки, разделитель полей `;`, десятичный разделитель чисел запятая.
Показатели относятся к разным периодам. Для денежных переводов в заголовке
указаны 2014-2018 годы, для государственного долга 2019 год, для резервов 2018 год.
Программа использует значения из файла без пересчёта на общий год.

Исходный файл имеет кодировку Windows-1252. Программа читает его в этой кодировке,
чтобы сохранить названия стран, в том числе `Côte d'Ivoire`.
Пустые числовые поля, `x` и `No data` означают отсутствие данных и превращаются
в `null`. При расчёте среднего программа пропускает такие значения.
Если чисел нет, максимум и среднее равны 0.0, как требуется в задании.

CSV находится в `src/main/resources`. Чтение через `getResourceAsStream`
позволяет найти его и при запуске из IDE, и внутри собранного JAR.
Парсер рассчитан на формат учебного файла: разделитель и перевод строки
не должны находиться внутри значения поля, в том числе в кавычках.
При неверном формате строки программа пропускает её и выводит номер и причину
пропуска в консоль. Служебные строки без названия страны в конце CSV
также пропускаются.

Отчёт сохраняется в UTF-8. Числовые показатели в нём округляются до двух знаков
после точки; количество записей выводится целым числом.

## Структура проекта

| Класс | Назначение |
|---|---|
| `Main` | Создаёт объекты приложения и запускает обработку данных |
| `ExposureRecord` | Хранит все 22 поля записи о стране |
| `ExposureReader` | Читает строки CSV из ресурсов приложения |
| `ExposureParser` | Преобразует одну строку CSV в объект |
| `ExposureRepository` | Хранит записи в Map и выполняет операции CRUD |
| `Analyzer` | Объявляет доступные операции анализа |
| `ExposureService` | Отбирает записи и вызывает классы расчётов |
| `Calculation<T>` | Задаёт общий интерфейс расчёта и выводит результат |
| `MaxCalculation`, `AverageCalculation` | Вычисляют максимум и среднее |
| `ReportWriter` | Формирует таблицы и записывает отчёт в файл |

## Работа с записями

Название страны служит уникальным ключом в Map. Для изменения записи используется
метод `update`. Название при этом остаётся прежним. Чтобы заменить его,
нужно удалить старую запись и создать новую.

Метод `findAll` возвращает новый список, содержащий объекты из хранилища.
Изменение состава этого списка не меняет состав Map. Само название страны
уже сохранённого объекта не следует менять через сеттер: для этого нужны
удаление и создание записи с новым ключом.
