# Экономическое воздействие COVID

Итоговое задание по дисциплине «Java для Data Science». Вариант 10.
Кирилов Андрей Сергеевич, группа ДФиАД25-1.

Консольное приложение читает учебный файл `Exposure.csv`, преобразует строки
в объекты стран и формирует отчёт. Файл взят из материалов дисциплины и сохранён
без изменений. Данные исторические; приложение не оценивает текущую ситуацию.

## Запуск

Нужен JDK 17 или новее. Откройте `pom.xml` в IntelliJ IDEA как Maven-проект,
выберите JDK и запустите `ru.netology.kirilov.Main`.

Либо соберите проект из его корневой папки:

```text
mvn clean package
java -jar target/covid-economic-exposure.jar
```

По умолчанию отчёт сохраняется в `report.txt` в текущей рабочей папке.
Другой путь можно передать единственным аргументом:

```text
java -jar target/covid-economic-exposure.jar results.txt
```

Родительская папка отчёта должна существовать. Приложение сообщает об ошибках
в стандартный поток ошибок и завершает работу с ненулевым кодом, если ресурс
недоступен, нарушен заголовок или не удалось записать отчёт.

## Что выводится

- Число стран и количество заполненных общих индексов.
- Максимальный и средний общий индекс экономической уязвимости.
- Уникальные группы дохода и число стран в каждой группе.
- Страна с максимальным общим индексом среди LIC.
- Страны, у которых индекс без помощи, ПИИ и импорта продовольствия находится
  в диапазоне от 5 до 6 включительно, и число стран LIC в этой выборке.
- Результаты создания, поиска, изменения и удаления отдельной учебной записи.

Учебная запись удаляется до расчёта показателей и не меняет исходную статистику.
Если максимум в группе делят несколько стран, возвращается первая по порядку CSV.

## Формат данных

В CSV 22 колонки с разделителем `;`. Числа используют десятичную запятую.
Показатели относятся к разным периодам: в заголовке для денежных переводов
указаны 2014-2018 годы, для государственного долга 2019 год, для резервов 2018 год.
При чтении сохраняются значения выданного файла; пересчёт на один год не проводится.
Кодировка исходного файла Windows-1252 сохраняет название `Côte d'Ivoire`.
Пустые значения, `x` и `No data` преобразуются в `null`. При вычислении среднего
они не считаются нулями и не входят в число наблюдений. Если чисел нет,
расчёт возвращает 0.0 по условию задания.

Чтение идёт из classpath через `getResourceAsStream`, поэтому программа работает
и из IDE, и из JAR. Parser рассчитан на формат выданного файла: без разделителей
и переводов строк внутри полей в кавычках. Это не универсальный CSV-парсер.
Повреждённые строки пропускаются с указанием номера и причины в консоли.
В конце выданного CSV есть служебные строки без названия страны; они также
пропускаются. Отчёт записывается в UTF-8, числовые результаты выводятся с двумя
знаками после точки.

## Классы

| Класс | Назначение |
|---|---|
| `Main` | Собирает приложение и запускает сценарий |
| `ExposureRecord` | Хранит все 22 поля записи |
| `ExposureReader` | Читает строки ресурса |
| `ExposureParser` | Преобразует одну строку в объект |
| `ExposureRepository` | Хранит записи в Map и выполняет CRUD |
| `Analyzer` | Задаёт контракт анализа |
| `ExposureService` | Формирует выборки и делегирует расчёты |
| `Calculation<T>` | Задаёт общий расчёт и метод вывода |
| `MaxCalculation`, `AverageCalculation` | Реализуют максимум и среднее |
| `ReportWriter` | Форматирует и сохраняет отчёт |

Ключ репозитория: точное название страны из CSV. При обновлении ключ не меняется;
для смены страны нужно удалить прежнюю запись и создать новую. Список из
`findAll` является копией коллекции, но содержит сами объекты модели.
При изменении страны следует пользоваться `update`, а не менять ключ у объекта
через сеттер после помещения в репозиторий.
